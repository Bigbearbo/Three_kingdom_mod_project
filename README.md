# TK3 Fenghuo Mod｜《全軍破敵：三國》烽火式改造計畫

狀態：**研究／規格與開發骨架 v0.1，尚未產出可在遊戲中使用的 `.pack` Mod。**
建立日期：2026-11-13

## 目標

保留《全軍破敵：三國》的戰場與人物養成優點，借鑑《烽火三國2》「人才稀缺、統兵能力差異、可選擇手動介入、戰役調度有價值」的設計。

此計畫**不是**聲稱完整重製《烽火三國2》。優先實現三件事：

1. 武將可帶兵力有明顯差異，但不把所有弱將都變成廢物；頂級將領應有不可替代的指揮價值。
2. 平時養兵成本下降；補員依實際損失後的補充量收費，讓戰損有經濟重量，而不是逼玩家反覆解散軍隊。
3. 透過與 AI、手動戰鬥、自動戰鬥、不同開局的對照測試，確認規則真的讓後期更耐玩。

## 優先級

| 階段 | 工作 | 驗收標準 |
|---|---|---|
| P0 | 核對遊戲版本、RPFM/Assembly Kit、既有 Mod、衝突 | 有可重現的純淨基準、資料表清單與實測記錄 |
| P1 | 分級帶兵量；原型 0.5 / 0.75 / 1.0 倍 | 名將與一般將領在相同兵種有可確認的人數差異；AI 能按規則招募 |
| P2 | 平時維持費約 0.5 倍＋補員成本 | 戰後、補員、合併、換將、破產不會雙扣或誤算 |
| P3 | 電腦招募／軍費適應 | 電腦能使用新兵種分級，沒有持續性免費補兵或無限破產漏洞 |
| P4 | 多劇本數值試玩 | 至少比較兩個開局、強弱勢力、手動／自動、前中後期 |
| P5 | 獨立劇本包 | 在不破壞核心模組的情況下，單獨調整原有年份曹操等勢力 |
| P6 | 研究長期俘虜、前線屯兵、永久戰損 | 可行性評估後再決定是否導入 Lua/DLL，不預先承諾 |

詳細工作與驗收：[`docs/00_ROADMAP.md`](docs/00_ROADMAP.md)

## 目錄

- `docs/`：決策、規格、工具調查與測試矩陣
- `config/balance_v0_1.json`：暫定設計參數（**非**遊戲可直接使用的格式）
- `tools/preview_economy.py`：獨立軍費公式預覽器（**非**遊戲 Mod）
- `tests/`：只測試預覽計算，不能代替遊戲驗收
- `mod_src/`：未來 `.pack` 來源表格、Lua 與封裝設定
- `scenarios/`：未來開局劇本方案；避免跟核心 Mod 綁在一起
- `AGENTS.md`：交給 Codex 的開發／測試規則

## 第一個測試假說（不是已驗證事實）

使用三級兵力版本，比例 50%／75%／100%。例：**某步兵**滿編基準120人，三等級依序為60／90／120。騎兵、器械等不同兵種**應依各自基準單位人數等比例換算**，不能讓每一種兵都硬變60／120人。

注意：編制級別要如何根據武將能力／等級／特性授予、舊單位如何保留經驗和傷亡，屬 P1 需要實際證明的機制；現階段沒有做出自動變更。

## 開發狀態與法律

目前僅建立原創專案文件與不依賴遊戲的公式預覽器。**未取得遊戲檔案、未執行 RPFM、未進行遊戲內測試；不可把規格當成已完成 Mod。**

勿提交原版遊戲資料、商用素材、他人未授權的 Mod 內容、Steam 登入資訊、存檔中的個資或可執行 DLL。要發布整合包，先確認第三方授權。
